# Citing BacLab

```{note}
The BacLab paper is in preparation. Until it is published please cite the software (see `CITATION.cff` in the repository). The reference will be:
*Yurtseven A, et al. BacLab: a self-hosted, containerized web platform for integrated bacterial genomics and genome mining. [Journal, year, DOI].*
```

Please also cite the tools you used: each tool page and every result archive (`CITATION.txt`) lists them, and the "methods text" of a run (my jobs -> details)
contains them ready to paste.

BacLab is released under the MIT licence.
