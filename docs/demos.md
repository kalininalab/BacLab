# Demonstrations

Three single HTML files show BacLab without installing it - no server behind them, everything runs in your browser. They were generated from a real installation with
real example data (*Klebsiella pneumoniae*, *Bacillus subtilis*, *Chlamydia trachomatis* genomes, 16S genes of 12 type strains) and randomly generated demonstration users.

```{raw} html
<p class="demo-links">
  <a href="demos/baclab-demo-site.html" target="_blank">Clickable site (visitor)</a>
  <a href="demos/baclab-demo-user.html" target="_blank">Logged-in lab member</a>
  <a href="demos/baclab-demo-admin.html" target="_blank">Administration</a>
</p>
```

## Clickable site
The real pages, as a visitor sees them: menus, tool pages, example results with working tables, trees, plots and reports. Submitting is blocked with a message.

## Logged-in lab member
Accounts, groups and "my jobs": the member's runs and the group's, key findings per run, methods text, projects, API keys, "use results in another tool".

## Administration
The administrator's pages: system status, usage, the live monitor (a snapshot), users and groups, job records, custom tools and databases, tool switches, job limits, e-mail policy.

```{note}
The demonstrations are static captures: the pages, tables, trees and plots behave as on a real installation, but nothing is computed or submitted. They need a current browser.
```
