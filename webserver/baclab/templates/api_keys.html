Using the key

With the baclab-client script from the BacLab folder:

export BACLAB_URL={{ site }}
export BACLAB_TOKEN=lm_...
./baclab-client tools
./baclab-client submit padloc genome1.fasta genome2.fasta --wait --download results.zip

or plain HTTP:

curl -H "Authorization: Bearer $BACLAB_TOKEN" -F genomes=@genome1.fasta {{ site }}/api/v1/jobs/padloc/submit/
curl -H "Authorization: Bearer $BACLAB_TOKEN" {{ site }}/api/v1/jobs/<job id>/
