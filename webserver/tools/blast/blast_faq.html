How to use BLAST?

You can input your sequences using one of the following methods:

1. Text input (FASTA format)

2. File upload (FASTA format (.fasta))

You can select BLAST type by using the dropdown

You can adjust the E-value cutoff or keep the default.

Click Submit to start the job. You will receive a job ID and be redirected to the results page. You can revisit later with that ID.

You can view BLAST results on the webpage

You can sort columns or search within the table interactively.

You can download results by clicking Download Results button.
