How to use Genome Mining?

You can input your sequence(s) using one of the following methods:

1. Text input (FASTA format)

2. File upload (FASTA format (.fasta, .fna, .faa))

Select the target Database from the dropdown.

You can optionally enable Run Homolog Search by checking the box.

Click Submit to begin mining. You will receive a job ID to check back on your results later.

Results will be displayed in an interactive table where you can filter and download the data.
