How to use phylogeny analysis?

Upload your 16S genomes FASTA format ('.fasta', '.fna'). Or type your own sequences in FASTA format in text input area.

Select the Phylogenetic Tree Tool (default is IQTree)

Click Submit to start the phylogeny job. You will receive a job ID and can revisit later.

Phylogeny results can be downloaded on results page.

The output will have '.dnd' and '.tree' (for IQTree) or '.nwk' (for FastTree) files.

You can visualize the phylogenetic tree using tools like iTOL.
