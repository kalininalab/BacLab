How to use taxonomy analysis?

You can check taxonomy of your strains in one of the following ways:

1. Using 16S rRNA sequence(s)

2. Using whole genome sequence(s)

For 16S: Upload your 16S sequence(s) FASTA format ('.fasta', '.fna'). Or type your sequence(s) in FASTA format in text input area. Then select Taxonomy Type as "16s rRNA (with NCBI taxonomy finder)"

For Whole genome: Upload your whole genome sequence(s) FASTA format ('.fasta', '.fna') (recommended). Or type your genome sequence(s) in FASTA format in text input area. Then select Taxonomy Type as "Whole genome (with GTDB-tk)".

Click Submit to start the phylogeny job. You will receive a job ID and can revisit later.

Taxonomy results can be seen and downloaded on results page.
